## Open-source work

### [appsettings-lint](https://github.com/alirezaRanjbar4/appsettings-lint)

Catch duplicate keys, missing required settings, and unresolved placeholders in `appsettings` JSON before deployment. A local .NET CLI with value-free reports, automated tests, and Windows/Linux/macOS CI.

[Quick start](https://github.com/alirezaRanjbar4/appsettings-lint#try-it-in-two-minutes) · [Releases](https://github.com/alirezaRanjbar4/appsettings-lint/releases) · [Report a problem](https://github.com/alirezaRanjbar4/appsettings-lint/issues/new/choose)

I welcome practical bug reports, small contributions, and discussions about .NET configuration and deployment tooling.
