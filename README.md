# Hi, I'm Alireza 👋

I build .NET applications and practical developer tools.

My work includes **C# · ASP.NET Core · Entity Framework Core · SQL Server · Blazor**. My current open-source work focuses on tooling around AI datasets, model training, evaluation, and application configuration.

## Projects

| Project | Problem it addresses |
| --- | --- |
| [TrainSet Guard](https://github.com/alirezaRanjbar4/trainset-guard) | Catch malformed chat fine-tuning examples, duplicate/conflicting prompts, and train/validation leakage. |
| [Text Train Kit](https://github.com/alirezaRanjbar4/text-train-kit) | Train, evaluate, save, and run an ML.NET text classifier entirely in C#, with independent validation. |
| [FineTune Eval](https://github.com/alirezaRanjbar4/finetune-eval) | Compare baseline and fine-tuned model outputs on a fixed reference set and gate regressions in CI. |
| [appsettings-lint](https://github.com/alirezaRanjbar4/appsettings-lint) | Find duplicate keys, missing required settings, and unresolved placeholders before deployment. |

Each project includes a CLI, synthetic examples, automated tests, and documentation. Text Train Kit trains traditional text classifiers; the other AI tools check training data and saved model outputs.

I welcome reproducible bug reports, small contributions, and discussions about practical .NET and AI tooling. Please use a project's Issues to share a concrete use case with a small, non-sensitive example.
